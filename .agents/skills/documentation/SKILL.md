# Documentation Skill

Use this skill when updating or adding documentation in `agnara-dependency-intelligence`.

## 1. Documentation Principles

- **Historical Accuracy:** Always reference `agnara==0.1.0a2` and CPython `>=3.14`. Never refer to future features or unreleased APIs.
- **Clear Separation:** Explicitly explain caller-owned vs runtime-owned parameters whenever discussing capabilities.
- **Standard Links:** Use proper Markdown links to files and documentation within the repo.
- **Forbidden Placeholders:** Never introduce temporary task markers, stub notes, mock domains, or incorrect repository URLs.
- **Canonical URLs:**
  - Application repo: `https://github.com/agnara-project/agnara-dependency-intelligence`
  - Upstream framework repo: `https://github.com/Blandskron/agnara`
  - Preceding application: `https://github.com/agnara-project/agnara-task-intelligence`
