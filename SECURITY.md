# Security Policy

## Historical Reference Status

`agnara-dependency-intelligence` is **Agnara Historical Reference Application #002**.

This repository is an educational, transport-neutral reference application intended to demonstrate Dependency Injection and runtime-owned parameters in `agnara==0.1.0a2`.

- It is **not** intended for direct production deployment.
- It makes no claim of benchmark leadership, SLA, or production security guarantees.
- It contains no credentials, secrets, remote network connections, or external storage dependencies.

## Reporting Security Vulnerabilities

If you discover a potential security vulnerability in the underlying Agnara framework itself, please report it privately to the Agnara maintainers:

- **Upstream Repository:** [https://github.com/Blandskron/agnara](https://github.com/Blandskron/agnara)
- **Email:** maintainers@agnara.dev

Please do not disclose security issues publicly in GitHub Issues before upstream maintainers have had an opportunity to address them.
